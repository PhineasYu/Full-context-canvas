# Full Context Canvas

> 你只管收藏。它负责归位、告诉你东西去了哪,并把散落的东西串成新想法。

一张把 Claude、ChatGPT、Gemini 聊天记录和 Chrome、YouTube、Reddit、X 收藏放在一起的白板。AI 自动分组,一条收藏可以同时属于多个组;点任意卡片,一根发光的线连回它的原平台;每个分组决定都有理由和把握度。

## 目录

| 路径 | 内容 |
|---|---|
| `prototype/index.html` | 可交互原型,直接用浏览器打开 |
| `prototype/app.html` | 原型源码(发布到 claude.ai 的版本) |
| `prototype/build.mjs` | 把 `app.html` 包成独立的 `index.html`:`node prototype/build.mjs` |
| `extension/` | Chrome 插件 MVP：读取全部书签，Claude 分组，实时同步。安装方法见 `extension/README.md` |
| `docs/RESEARCH.md` | 竞品调研、定位和下一步建议 |
| `docs/PRODUCT_PLAN.md` | 产品定义、3 分钟演示脚本、技术方案、开发路线、投资人问答 |

## 原型能做什么

- **演示导览**:顶栏「演示导览」11 步讲完整个故事;链接末尾加 `#tour` 可直接进入
- **整理前 / 整理后**:7 个平台各自一列 ↔ 一张白板,卡片飞过去
- **交汇点**:任意两个组的交集,连回各自的平台(盘点页和分组页里都能进入)
- **白板**:7 个平台的 41 条示例收藏,自动分成 6 个互相重叠的组;拖动平移,滚轮/双指缩放,缩远后变成总览
- **来源线**:点卡片,发光的线连回原平台;点左侧平台图标,该平台的全部收藏一起连线
- **透明度**:原件位置、「原件没有被移动」、每组理由和把握度、完整的整理记录
- **待确认**:AI 拿不准的集中列出,一键确认或移出,改动写进记录
- **持续流入**:「模拟一条新收藏」,新卡片从平台飞进对应分组
- **真实导入**:Claude / ChatGPT 导出的 `conversations.json`、Google Takeout、浏览器书签 HTML、Chrome `Bookmarks` 文件、链接列表
- **综合生成**:跨平台写简历、找兴趣交汇点、整理创业资料,每句话都带可点击的出处
- **跨平台搜索**、**盘点**、**中英文切换**

在 claude.ai 上打开时,综合生成和导入分类会调用真实的 Claude(首次需要授权);本地打开或无法调用时自动切换为离线演示,并在界面上标明。
